> 似乎是学了教资吧？看人物了一段时间，也喜欢看看这个人的教育观、学生观、教师观搞得如何。可能是不太喜欢这个专业吧？在面对“全员参与”的比赛的时候，尤其是任务突然堆起来的时候，会直接产生排斥心理。

其实在最近吧，我也一直在想我们学校的一件事情。就我之前的那篇文章也就提到了我这个事情[^1]：“学校天天能整活，没人参加比赛？那就全员参与。”这件事情倒还真是真的，确实是这样。这个时候就可以说到 git 的好了，可以直接看到是在2026-10-26 18:04，我写下的这段话。

那个时候我们还以为又是一件比赛而已。为什么说“又”呢？其实上个学期（大二下）也是这样的。当时那个是叫什么“未来设计师”的。并且呢，其实大一上学期也有过一次，但当时的老师没有说的很明显，只是说“各位先干着，干得好可以参加比赛，干的不好也就算课程分数啦”。可是从大二下开始，这件事情就直接变成了我在上个月所说的——“没人参加比赛？那就全员参与”的性质。

并且，从这次开始，原来课程的事情，授课任务不干了；取而代之的是在课上给老师看方案、看进度。原来的课？不上啦，完全用来干这个。这也是我完全无法理解的一个地方。我也知道可能是我太过于矫情，可能是我没经历过社会的“毒打”，但正如我之前说的那样，想到什么就写什么，这也是我们博客网站的独立性质之处；并且，留下这个时候我的一些态度、想法，之后也是一份回忆。

那么说回这件事情哈。这种东西，什么“获奖”呢，我个人其实——真的不太在乎。我也不知道为什么我会这么想，可能是我这个人比较内向（I吧），就是我自己脑子里面定下的时间表，我就觉得很舒服。比如没课的下午就去图书馆写代码、写文章；或者没事情干，看身体如何，如果可以，还可能即兴去一趟花桥地铁站（江苏昆山），拍张照片就回来。并且我自己的学业呢，我也有自己的升学计划，目前还是不太想在这里说，之后有的是时间哈哈。也可能是我这个人不太喜欢这个专业，自然也就不愿意投入太多的时间在这上面。这也是我为什么专科以来，其实没有怎么在这个专业上得奖的原因。当然如果说什么学校颁发的荣誉——呃，一个先进个人而已。

刚刚一直在说我对于这个比赛的看法哈，那么接下来我来说一下怎么就“从比赛看‘人物’”了。虽然本次教资分数没有合格，但是做老师是不会停下来滴。这也是我这辈子最大的愿望之一。我在去年的年终总结说过，“我见过坏老师，所以知道好老师是什么。我见过好老师，就更明白如何成为好老师”，这句话即使时隔11.5个月，我还是那么认同。

给我们上这门课的老师，估计还是大学刚刚毕业出来。我也只是在和她相处的这断断续续的2个月内，似乎是看到了她的优点和缺点。事先说明，我不是对老师指手画脚，我也知道尊师重道哈。只是客观的评价一下，对事不对人。

优点自然就是负责任啦。其实这个老师似乎是认识了我，也每次上课的时候都会找我，说“这个搞得怎么样了？”“那个软件学起来还行吧？”这种。总比有些老师扔个作业出来，然后啥都不管好太多了。同时，也算是认可我的能力的。我们这个比赛总共有3个“作品”要交，她主动找我，说“获奖的概率挺大的”，这一点，也很不错。

但缺点也很明显。我最近又要去医院看牙去，她周一晚上找我的时候，我也对她说过，我接下来还要接受治疗，真的来不及。结果她来了一句“这有什么大不了的，抽几个晚上就来得及了”。还有一点：我们这个作业是分组完成了，我和A、B一组。结果她看到A、B不干活，居然希望我把剩下两个作品一起搞了。她明知道剩下的组员天天摸鱼，结果却试图通过增加我的任务量，来完成学校交付给她的人物。并且最后一点：我也通过和她说“我接下来还有英语六级要考，真的来不及，我还想要去复习”，说着把上次296分给她看。结果她来一句什么？“这次合格也挺难，还不如搞搞这个比赛，之后考研究生的复试用得上。英语六级没什么用，我周末考教资也没有复习的……”。我后续还把我的升学计划（专升本之后的哈）说给她听，以此证明我真的是不喜欢这个专业，结果她又来一句“你疯了吗？”，类似是这句哈。

再次说明，我这个人在评价别人的时候，是对事不对人的。我也不是通过列举更多，文本字数更长，来试图贬低某个人，只是我作为一个学习教资的人，和她一样，都想要，或者已经走着教育行业。

我可能也和《士兵突击》的成才一样，目前“任何团体和个人都无法在心里占有一席之地”。我可能也是这样吧……？这一切也需要时间来告诉我答案。

一眨眼，写了1700多字，其实这篇文章也没什么太大的意思，可能是发发牢骚而已。这周过得挺慢的，现在嘴里、手上还有点橡胶手套的味道，等下去洗个手吧。
